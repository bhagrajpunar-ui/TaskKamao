0. Shuru karne se pehle — 5 zaroori baatein (dhyan se padhein)

1. Kamai ki koi guarantee nahi. Users ko jo paise milte hain woh aapki ad/offerwall kamai se aate hain. Agar ad revenue kam hai aur payout zyada, to nuksaan aapka hai. App mein ya Play Store par "roz ₹500 kamao", "ghar baithe income", "sote-sote kamao" jaisi baatein kabhi na likhein — Google Play misleading claims par app hata deta hai.
2. "Add Money" / deposit nahi hai — aur add bhi mat karna. Users se paisa lekar rakhne ke liye RBI ka PPI license chahiye. Yeh app sirf kamaye hue rewards UPI par bhejta hai.
3. Video ads ke coins withdraw nahi hote (by default). Google AdMob ki policy ("Policies for ad units that offer rewards") ke hisaab se rewarded video ke badle aisa reward nahi de sakte jo cash mein badla ja sake. Isliye code mein video dekhne par "video points" milte hain (sirf leaderboard ke liye). Withdraw hone wale coins quiz, check-in, spin, scratch, offers aur referral se aate hain. Ise badalne ki koshish na karein, warna AdMob account band ho sakta hai.
4. Legal/CA salah lein. Rewards par TDS/GST, spin/scratch jaise chance-based features, aur India ke online gaming niyam — launch se pehle ek CA/lawyer se baat zaroor karein. Spin aur scratch ko admin panel se kabhi bhi band kar sakte hain (Tasks > active = false).
5. Kharcha pehle se socho. Default mein daily check-in 50 coins (₹0.50) hai. 1,000 users roz check-in karein to sirf check-in ka kharcha ₹500/din = ₹15,000/mahina. Shuruaat mein admin panel > Config mein checkinCoins kam (jaise 5–10) rakhna samajhdari hai, jab tak asli kamai ka andaza na lage.

2. Apne PC (Windows) par tools install karna

Developer ko de rahe ho to yeh section unka hai. Khud kar rahe ho to ek-ek karke karein:

  1. Git: git-scm.com > Download for Windows > install (sab default).
  2. Node.js 20 LTS: nodejs.org > "20.x LTS" installer > install. Check: CMD kholkar node -v (v20.x dikhna chahiye).
  3. Android Studio: developer.android.com/studio > Download > install. Pehli baar kholne par "Standard" setup chunein (Android SDK, emulator aa jayega).
    Android Studio > More Actions > SDK Manager > SDK Platforms: Android 15 (API 35) tick > SDK Tools: "Android SDK Command-line Tools" tick > Apply.
  4. Flutter SDK: docs.flutter.dev > Get started > Install > Windows > Android > zip download karein (stable, 3.24 ya naya).
    Zip ko C:\src\flutter mein extract karein (Program Files mein nahi).
    Start > "Edit the system environment variables" > Environment Variables > User variables > Path > Edit > New > C:\src\flutter\bin > OK.
  5. Naya CMD kholein aur chalayein: 
    flutter doctor
flutter doctor --android-licenses     (sab mein "y" dabayein)
    Jab tak "Flutter" aur "Android toolchain" ke aage ✓ na aaye, jo bataya jaye woh fix karein.
  6. Firebase CLI: 
    npm install -g firebase-tools
firebase login
  7. Project zip (TaskKamao_source.zip) ko C:\projects\taskkamao mein extract karein. Aage ke saare commands isi folder se.

3. Firebase project banana (exact click path)

3.1 Project

console.firebase.google.com > Create a project (ya "Add project") > Name: TaskKamao > Continue > Google Analytics (on rakh sakte hain) > Create project.

Project ID note karein (jaise taskkamao-1a2b3). File .firebaserc kholkar YOUR-FIREBASE-PROJECT-ID ki jagah yeh ID likhein.

3.2 Blaze plan + budget alert

Console mein neeche-left plan ka naam (Spark) > Upgrade > Blaze > billing account banayein/chunein (card) > budget amount set karein (jaise ₹1,000) > Purchase.

Alag se: console.cloud.google.com > Billing > Budgets & alerts > Create budget > ₹1,000 > alerts 50%/90%/100% par email.

3.3 Login (Phone OTP) chalu karna

Build (left menu) > Authentication > Get started > Sign-in method > Phone > Enable > Save.
Isi page par Email/Password > Enable > Save (yeh sirf admin panel login ke liye hai).
Authentication > Settings > SMS region policy > Allow > sirf India chunein > Save. (SMS fraud se bachata hai.)
Testing ke liye: Sign-in method > Phone > Phone numbers for testing > ek number + 6 digit code daalein (jaise +91 99999 00001 / 123456). Play Store review team ko bhi yahi dena hai.

3.4 Database (Firestore)

Build > Firestore Database > Create database > Location: asia-south1 (Mumbai) > Start in production mode > Create.

Location baad mein badal nahi sakte. Code bhi Mumbai region (asia-south1) maan kar likha hai.

3.5 Android app jodna + google-services.json

  1. Pehle SHA-1 nikalein (PC par, project folder mein): 
    cd app
flutter pub get
cd android
gradlew signingReport
    Output mein "Variant: debug" ke neeche SHA1 aur SHA-256 copy karein.
    Yeh command na chale to debug key seedha keytool se dekh sakte hain: 
    keytool -list -v -keystore "%USERPROFILE%\.android\debug.keystore" -alias androiddebugkey -storepass android -keypass android
  2. Project Overview ke paas ⚙️ (gear) > Project settings > General > neeche "Your apps" > Android icon > Package name: com.taskkamao.app > Nickname: TaskKamao > Debug SHA-1 paste > Register app > Download google-services.json.
  3. File ko yahan rakhein: app\android\app\google-services.json (baaki Firebase steps "Next" karke skip kar sakte hain — code mein pehle se hai).
  4. Usi page par app ke neeche Add fingerprint se SHA-256 bhi daalein. Release keystore banane ke baad (Section 8) uska SHA-1/SHA-256 bhi daalna, aur Play Console > Test and release > Setup > App signing wale "App signing key certificate" ke SHA-1/SHA-256 bhi. Yeh na kiya to Play Store wale app mein OTP nahi aayega.

3.6 Web app config (admin panel ke liye)

Project settings > General > Your apps > Add app > Web (</>) > Nickname: TaskKamao Admin > Register > jo firebaseConfig = {...} dikhe use copy karein.

admin\index.html kholein, const firebaseConfig = { apiKey: "TODO", ...} waali jagah apni values paste karein. (Yeh web keys secret nahi hain; security rules aur admin claim se hoti hai.)

3.7 Service account key (seed aur admin script ke liye)

Project settings > Service accounts > Firebase Admin SDK > Generate new private key > Generate key.

Downloaded JSON ko functions\serviceAccount.json naam se save karein. Yeh file kisi ko na bhejein, GitHub par na daalein.

5. Backend deploy karna (Functions + Rules)

CMD project folder (C:\projects\taskkamao) mein:

firebase use --add                 (apna project chunein, alias: default)
cd functions
npm install
cd ..

5.1 Secrets daalna (RazorpayX keys yahan jaati hain — code mein nahi)

Pehle RazorpayX ki Test mode keys use karein (Section 7). Har command par value paste karke Enter:

firebase functions:secrets:set RAZORPAYX_KEY_ID
firebase functions:secrets:set RAZORPAYX_KEY_SECRET
firebase functions:secrets:set RAZORPAYX_WEBHOOK_SECRET
firebase functions:secrets:set OFFERWALL_SECRET

WEBHOOK_SECRET aur OFFERWALL_SECRET aap khud koi lamba random password bana sakte hain (20+ characters). Webhook wala RazorpayX dashboard mein bhi same daalna hai.

5.2 Deploy

firebase deploy --only firestore:rules,firestore:indexes
firebase deploy --only functions

Pehli baar RAZORPAYX_ACCOUNT_NUMBER poochega — RazorpayX dashboard se apna account number daalein (abhi na ho to test account number). Indexes banne mein 5–10 minute lag sakte hain.

Deploy ke baad: Firebase Console > Build > Functions — list mein verifyRewardedAd, razorpayWebhook, offerwallPostback ke URL dikhenge (jaise https://asia-south1-PROJECT.cloudfunctions.net/verifyRewardedAd). Inhe note karein.

5.3 Tasks, quiz aur config daalna (seed) + admin banana

cd functions
set GOOGLE_APPLICATION_CREDENTIALS=serviceAccount.json
npm run seed
Firebase Console > Authentication > Users > Add user > apna admin email + strong password.
node scripts/setAdmin.js aapka-admin@email.com
cd ..
firebase deploy --only hosting

Ab https://PROJECT-ID.web.app kholkar admin email/password se login karein. Yahan se: pending withdrawals, KYC verify, users block/unblock, tasks aur quiz add, config badalna.

6. Google AdMob setup

  1. admob.google.com > Sign up (business Gmail) > country India, payment details.
  2. Apps > Add app > Android > "Is the app listed on a supported app store?" > No (abhi) > App name: TaskKamao > Add app.
    App ID (ca-app-pub-XXXX~YYYY) copy karke AndroidManifest.xml mein TEST id ki jagah daalein.
  3. App > Ad units > Add ad unit > Rewarded > Name: video_task > Reward amount: 5, Reward item: points > Server-side verification: callback URL mein verifyRewardedAd ka URL > Create ad unit.
    Ad unit ID (ca-app-pub-XXXX/ZZZZ) ko app_config.dart ke rewardedAdUnitId mein daalein.
  4. Development ke time apne phone ko test device banayein (AdMob > Settings > Test devices) — apne hi ads par click karna AdMob account ban karwa sakta hai.
  5. App Play Store par aane ke baad: AdMob > App settings > Link to app store, aur website par app-ads.txt lagayein (AdMob batata hai kya likhna hai).
Rewarded ad tabhi dikhna chahiye jab user khud button dabaye, aur pehle saaf likha ho ki kya milega ("+5 pts"). App mein yeh pehle se aisa hi bana hai. "Ad dekh kar humari madad karein" jaisa text na likhein.

7. RazorpayX (UPI payout) setup

  1. x.razorpay.com > Sign up > business type chunein > business PAN, GST (agar hai), bank account, address > documents upload > KYC/verification ka intezaar.
  2. Current account khulwane / activate hone ke baad usme funds daalein (payout isi balance se jaata hai).
  3. Dashboard > Account & Settings (ya Settings) > API Keys > Generate Key > Key ID + Key Secret copy (secret dobara nahi dikhega).
    Inhe Section 5.1 wale commands se secrets mein daalein. Shuru mein Test Mode keys.
  4. Settings > Webhooks > Add New Webhook > URL: razorpayWebhook ka URL > Secret: wahi jo RAZORPAYX_WEBHOOK_SECRET mein daala > Events: payout.processed, payout.failed, payout.reversed, payout.rejected, payout.updated > Save.
  5. Account number (dashboard par dikhta hai) deploy ke time RAZORPAYX_ACCOUNT_NUMBER mein jaata hai.
  6. Test mode mein poora flow chalayein (Section 10). Sab sahi ho tab Live keys se secrets update karein: 
    firebase functions:secrets:set RAZORPAYX_KEY_ID      (live key)
firebase functions:secrets:set RAZORPAYX_KEY_SECRET  (live secret)
firebase deploy --only functions
Business registration/GST nahi hai to RazorpayX ya Cashfree approval mushkil ho sakta hai. Pehle proprietorship + Udyam/GST ke baare mein apne CA se baat karein. Bina payout partner ke withdrawal feature live na karein — admin panel > Config mein "payoutsEnabled": false rakh sakte hain.

8. App chalana aur Release build (AAB) banana

8.1 Phone par test

Phone mein: Settings > About phone > Build number par 7 baar tap (Developer options) > Developer options > USB debugging ON. USB se PC se jodein.

cd app
flutter pub get
flutter run

8.2 Upload keystore (sirf ek baar — file aur password sambhal kar rakhein)

cd app\android\app
keytool -genkey -v -keystore upload-keystore.jks -keyalg RSA -keysize 2048 -validity 10000 -alias upload

"keytool not found" aaye to Android Studio ke andar wala use karein: "C:\Program Files\Android\Android Studio\jbr\bin\keytool"

app\android\key.properties.example ko copy karke app\android\key.properties banayein aur passwords bharein (storeFile=upload-keystore.jks).

8.3 Build

cd app
flutter build appbundle --release

Output: app\build\app\outputs\bundle\release\app-release.aab — yahi Play Console par upload hoti hai. (Side-testing ke liye flutter build apk --release.)

Har naye version se pehle app/pubspec.yaml mein version: 1.0.0+1 ka aakhri number badhayein (1.0.1+2, ...).

10. Testing checklist (launch se pehle sab tick karein)

  • Naye number se OTP login hota hai; galat OTP par error aata hai
  • Signup par referral code daalne se friend ki list mein "Pending" dikhta hai; galat code par "bina referral aage badho" option aata hai
  • Usi phone par doosre number se login karne par "ek device par ek account" error aata hai
  • Daily check-in ek hi baar hota hai; agle din streak +1; ek din chhodne par streak 1 se shuru
  • Quiz: sahi jawab par coins, galat par 0; wahi sawal dobara nahi aata; daily limit ke baad roka jata hai
  • Spin 1/din, scratch 3/din; limit ke baad error
  • Video (test ad): poora dekhne par "video points" aate hain; beech mein band karne par kuch nahi; withdraw balance nahi badhta
  • Firestore console mein app se balance badalne ki koshish (ya rules playground) — deny honi chahiye
  • KYC submit > admin panel mein dikhe > Verify > app mein Verified
  • Same PAN doosre account se — error
  • ₹50 se kam withdrawal blocked; UPI galat format blocked; ek pending ke rehte doosra blocked
  • Withdrawal request par balance turant ghatta hai ("Withdrawal mein" dikhta hai)
  • Admin Reject > coins wapas + "Refund" history mein
  • Admin Approve (RazorpayX TEST mode) > webhook se status "paid"; test failure par coins refund
  • Friend 2,000 task coins tak pahunche > referrer +1,000, friend +500; uske baad 10% commission dikhe
  • Dark mode, FAQ, Privacy/Terms links khulte hain; Logout; Account delete request
  • Release AAB par OTP chalta hai (release + Play signing SHA keys Firebase mein daali hain)
  • Firebase Console > Functions > Logs mein koi laal (error) entry nahi
  • App Check (Play Integrity) register karke ENFORCE_APP_CHECK = true karke functions dobara deploy
